# 06_GEG-SH — Gene/Element Context of Safe Harbor Candidates

Annotates candidate loci from `05_SHIP/` against the gene models and
regulatory elements of ROS_Cfam_1.0: nearest gene, distance to TSS,
overlap with exons/introns/regulatory annotation, and any known
disease/phenotype association — the context needed to judge whether a
high-scoring locus is actually safe to disrupt.
